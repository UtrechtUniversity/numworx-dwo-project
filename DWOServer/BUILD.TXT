For building a release please first built a release DWOJApplet. This will produce 
a DWOJApplet-*-with-dependencies.jar that is signed and obfuscated. Then building
DWOServer will copy the signed and obfuscated jar into the war for  production 
release. this should happen if the parent project is build 

mvn package

Verify the context.xml for the proper jars, resources and apps locations.
