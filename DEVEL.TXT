The app supports an javascript api. Samples of these are stored in the directories war/html5plain.html,
war/js-plainui/ and package nl.uu.fi.dwo.lms.gwtclient.gwt.jsdisplays.

In the javascript console one can access the api using:

var dpf = dwoAPI.DwoPresenterFactory.getDwoPresenterFactory();
pf = dpf.getFac();

pf will contain contain a presenterfactory in which every returned presenter  
will contain the documented call-backs in the jsdisplays package.
